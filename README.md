# Packrivo Social Desk 1.0 · 本地桌面预览

双击 `index.html`，用电脑浏览器打开。此版本由本地 HTML、CSS 和 JavaScript 组成，无需安装依赖或启动服务器。若浏览器限制本地页面存储，页面会提示；请使用“导出备份”保存 JSON。

界面采用深色工作台主题。26 个渠道使用保存在 `assets/brand-icons/` 的品牌 SVG，因此不依赖图标 CDN。图形来自 [Simple Icons](https://simpleicons.org/) 16.33.0；其图形文件以 CC0 提供，但各品牌商标和使用规范仍归对应权利人。LinkedIn 与部分行业媒体保留文字标记，避免把未获明确许可的图形冒充官方授权标志。

## 现在可以做什么

- 在“社媒账号”按类别查看 30 多个海外社媒、社区、行业媒体和地区平台的入口；手工记录注册进度和公开主页地址。
- 在“内容工作室”创建母稿、为各平台写独立版本，完成事实、素材、标注与受众审核。
- 在“发布日历与队列”安排日期、复制文案、打开平台；亲自发出帖子后再回填公开 URL 与时间。
- 修改已审核内容后，工作台会要求重新核验。默认待处理队列不把草稿当成可发布任务；“复制发布包”包含正文与标签，图片说明可单独复制。
- 在“内容与素材库”登记素材引用，在“结果记录”手工填写阅读、点击、询盘和 GEO 观察。
- 通过右上角导出或导入 JSON 备份。数据保存在当前浏览器的本机存储中，不含密码、Cookie 或 OAuth 令牌。

## 建议的第一条流程

注册真实个人 LinkedIn 账号并建立 Packrivo 公司主页 → 在工作台创建一条包装知识母稿 → 写 LinkedIn 公司主页版本 → 完成四项人工审核 → 排期 → 复制并打开 LinkedIn → 手工发布 → 回填公开帖子链接。

Reddit、Quora、Shopify Community 等社区按具体问题逐帖参与；行业媒体按编辑投稿流程准备，不应复制同一条推广贴群发。

## 当前边界

这是一版可交互的本地 UI，不是已安装的 Windows 应用，也没有连接任何真实社媒账号。页面“打开平台”只打开对应网站，不会自动上传或发布。平台入口及资格可能变化，注册时以平台现场页面为准。浏览器清理站点数据可能移除本机记录，请定期导出备份。下一阶段的方向见 [ROADMAP.md](./ROADMAP.md)。

发布回填只做 URL 格式与平台域名检查，**无法证明帖子真实存在**。本地审查与未完成的视觉验收见 [REVIEW_NOTES.md](./REVIEW_NOTES.md)。图标来源见 [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md)。

本地状态逻辑可用 `node qa-state.mjs` 检查；它不代替真实浏览器里的视觉与点击验收。
